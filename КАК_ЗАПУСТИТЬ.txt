ОШИБКА "папка portal не найдена"
================================

У вас папка называется с (5) в конце, например:
  arhiv-cursor-continue-our-site-10a4 (5)

В терминале путь ДОЛЖЕН быть с (5):

  cd "C:\Users\Нияз\Downloads\arhiv-cursor-continue-our-site-10a4 (5)\portal"

Потом:
  npm install
  npm run build
  set NODE_ENV=production
  node server/index.mjs

САМЫЙ ПРОСТОЙ СПОСОБ (без терминала)
====================================

1. Проводник → зайдите в папку  portal  (внутри вашего проекта)
2. Дважды щёлкните  ЗАПУСК.bat
3. Не закрывайте окно "CGA Server"
4. Браузер: http://127.0.0.1:8080/

Или в корне проекта:  ОТКРЫТЬ-САЙТ.bat
