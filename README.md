# ЦГА ВКО — портал архива (своя версия)

Сайт написан **с нуля** в Cursor: React + SQLite на вашем компьютере.

**Без Lovable, без Supabase, без чужих ключей.**

## Запуск (один клик)

Дважды щёлкните **`START.bat`** в корне репозитория.

Откроется **http://127.0.0.1:8080/**

| Что | Как |
|-----|-----|
| Заявки | Формы на сайте → база `portal/data/archive.db` |
| Служебный вход | http://127.0.0.1:8080/staff |
| Код | `ARHIV-VKO-2026` |
| Пароль | `admin2026` |
| Панель | http://127.0.0.1:8080/admin |

## Разработка

```bash
cd portal
npm install
npm run dev
```

## Структура

```
portal/
  src/          — сайт (React)
  server/       — API и SQLite
  data/         — база (создаётся сама)
```

Старая зеркальная копия Lovable (если осталась) в корне — **не используется**.
