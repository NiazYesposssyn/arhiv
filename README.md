# ArchiveDesk

Статический сайт на тему проектирования системы управления доступом к архивной
информации и обработки результатов запросов.

## Что есть на сайте

- описание задач архивной системы;
- роли пользователей и уровни доступа;
- жизненный цикл архивного запроса;
- интерактивная демонстрация фильтрации результатов по роли и типу документа;
- форма создания заявки на архивную информацию.

## Запуск

Откройте файл `index.html` в браузере.
