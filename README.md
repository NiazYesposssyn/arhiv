# АрхивON

Готовый статический сайт-проект на тему цифрового архива и центра архивных услуг.
Интерфейс сделан в стиле современного сервисного портала: каталог, онлайн-заявка,
электронная очередь, помощник по выбору услуги, избранное и адаптивный дизайн.

## Что внутри

- Главная страница с премиальным hero-блоком, поиском и статистикой.
- Раздел услуг: архивные справки, цифровые копии, генеалогия, читальный зал.
- Интерактивный каталог с фильтрами по типу, региону, периоду и текстовому поиску.
- Избранное для архивных материалов.
- Онлайн-заявка с предварительным расчетом срока и демо-заполнением.
- Электронная запись в архивный центр с выбором филиала, даты и времени.
- Умный помощник, который подбирает услугу и список документов.
- FAQ, модальное окно подтверждения, темная/светлая тема, мобильное меню.

## Запуск

Откройте файл `index.html` в браузере.

Для локального сервера можно использовать любую простую раздачу статических файлов, например:

```bash
python3 -m http.server 8000
```

После запуска перейдите по адресу:

```text
http://localhost:8000
```

## Файлы проекта

- `index.html` - структура сайта.
- `styles.css` - современный адаптивный дизайн.
- `app.js` - интерактивные функции сайта.
- `Untitled-1.html` - совместимый переход на главную страницу.
