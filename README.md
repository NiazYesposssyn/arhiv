# E-Archive

Полноценный демонстрационный сайт архивного центра в стиле государственных сервисов: шапка, навигация, онлайн-услуги, электронный каталог, филиалы, новости, контакты и форма заявки.

## Как открыть

Откройте файл `index.html` в браузере.

Дополнительно можно запустить локальный сервер:

```bash
python3 -m http.server 8080
```

После запуска перейдите по адресу `http://localhost:8080`.

## Что есть на сайте

- главный экран с быстрым поиском;
- карточки архивных услуг;
- интерактивный каталог с фильтрами по региону и типу документа;
- инструкция получения архивной справки;
- раскрывающийся список филиалов;
- новости и контактная форма;
- мобильная адаптация, крупный шрифт и контрастный режим.
