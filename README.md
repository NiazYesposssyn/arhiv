# Archive Access System

Самодостаточный HTML-прототип государственного корпоративного архивного портала.

## Запуск

Откройте `index.html` в браузере. Файл `Untitled-1.html` оставлен как совместимый вход и перенаправляет на основной портал.

## Что включено

- публичная часть: landing page, о системе, архив, услуги, тарифы, новости, FAQ, контакты, справочный центр, юридические страницы и карта сайта;
- авторизация: вход, регистрация, восстановление пароля, 2FA и подтверждение Email;
- личный кабинет: dashboard, документы, архивные запросы, аналитика, карта филиалов, уведомления, история действий, отчеты, профиль и настройки;
- панель администратора: управление пользователями, ролями, документами, архивами, филиалами, категориями, новостями, справочником, заявками, аудитом, уведомлениями, тарифами, резервным копированием, системными настройками и мониторингом;
- современный UI: фиксированный navbar, mega-menu, glassmorphism, темная/светлая тема, адаптивность, карточки, KPI, таблицы, диаграммы, skeleton loading и плавные анимации.
- premium SaaS landing в стиле Azure/Stripe/Linear: казахский hero, 3D-иллюстрация, интерактивное демо продукта, карта Казахстана, тарифы, отзывы, FAQ и расширенный бизнес-workspace после входа.
