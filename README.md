# QazArchive

Готовый статический сайт-проект на тему архивов Казахстана.

## Что есть на сайте

- современная главная страница с описанием проекта;
- регистрация и вход в личный кабинет через `localStorage`;
- верхнее меню после входа: введение, услуги, справки/PDF, карта, контакты, AI-ассистент;
- форма онлайн-заявки на архивную услугу;
- генерация PDF-шаблона заявления прямо в браузере;
- интерактивная схема карты Казахстана с городами и архивными точками;
- настоящая интерактивная карта на Leaflet/OpenStreetMap с масштабированием, перемещением, маркерами и ссылками на 2GIS;
- реальные архивные учреждения в демо-данных: Национальный архив Республики Казахстан и Центральный государственный архив Республики Казахстан;
- локальный AI-ассистент с ответами по архивным услугам.

## Как открыть

Откройте файл `index.html` в браузере.

Также старый файл `Untitled-1.html` перенаправляет на главную страницу проекта.

## Важно

Это учебный фронтенд-проект без сервера. Пользователи и сессия сохраняются только в браузере. Для реального запуска нужно подключить backend, базу данных и официальные API/контакты архивных учреждений.

Для интерактивной карты нужен интернет, потому что тайлы карты и Leaflet подключаются через CDN.
