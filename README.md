# Архивный ЦОН

Готовый статический сайт-проект на тему электронного архива в стиле портала обслуживания населения.

## Что внутри

- современная главная страница `index.html`;
- адаптивная верстка для компьютера и телефона;
- каталог архивных услуг с поиском и фильтром;
- форма электронной заявки с проверкой ИИН;
- блок проверки статуса обращения;
- интерактивная карта Казахстана с точками ЦОН по городам и ссылками на 2ГИС;
- встроенный ИИ-ассистент для быстрых ответов по услугам, заявке, статусу и карте;
- FAQ, контакты и описание процесса получения услуги;
- отдельные файлы `styles.css` и `script.js`.

## Как запустить

Откройте файл `index.html` в браузере.

Также можно запустить локальный сервер:

```bash
python3 -m http.server 8080
```

После запуска откройте:

```text
http://localhost:8080
```

## Примечание

Это готовый фронтенд-макет. Для реального государственного сервиса потребуется подключить серверную часть, базу данных, авторизацию, хранение файлов, интеграцию с ЭЦП/EGOV и настоящий ИИ API.

Карта работает через Leaflet и OpenStreetMap, а у точек есть ссылки для проверки в 2ГИС. Перед реальным визитом в ЦОН нужно уточнять график по 1414, gov4c.kz или 2ГИС.
