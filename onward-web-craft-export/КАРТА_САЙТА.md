# Карта сайта — что где лежит

## Редактировать тексты (просто)

| Страница в браузере | Файл с текстами |
|---------------------|-----------------|
| `/` Главная | `src/content/home.ts` |
| `/collections` Фонды | `src/content/fonds.ts` |
| `/contact` Контакты | `src/content/contacts.ts` |
| `/services` Услуги | `src/content/uslugi.ts` |
| Меню, подвал (RU) | `src/content/texts.ru.ts` |

## Страницы (код вёрстки)

| URL | Файл |
|-----|------|
| `/` | `src/routes/index.tsx` |
| `/services` | `src/routes/services.tsx` |
| `/services/...` | `src/routes/services.$slug.tsx` |
| `/collections` | `src/routes/collections.tsx` |
| `/digital` | `src/routes/digital.tsx` |
| `/map` | `src/routes/map.tsx` |
| `/about` | `src/routes/about.tsx` |
| `/contact` | `src/routes/contact.tsx` |
| `/auth` | `src/routes/auth.tsx` |

## Общие части

| Часть | Файл |
|-------|------|
| Шапка | `src/components/SiteHeader.tsx` |
| Подвал | `src/components/SiteFooter.tsx` |
| Картинки | `src/assets/` |

## Можно не открывать

- `node_modules/` — библиотеки
- `components/ui/` — кнопки и поля (шаблон)
- `.lovable/`, `supabase/migrations/` — служебное
- `src/routeTree.gen.ts` — генерируется автоматически

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:8080).
