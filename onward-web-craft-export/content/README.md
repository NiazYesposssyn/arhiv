# Папка `content` — редактируйте сайт здесь

Все **тексты и данные** вынесены сюда, чтобы не искать их по десяткам файлов Lovable.

| Файл | Что менять |
|------|------------|
| `home.ts` | Главная: заголовок, цифры, новости, блоки |
| `fonds.ts` | Страница «Фонды» и фильтры |
| `contacts.ts` | Контакты, адрес, форма заявки |
| `uslugi.ts` | Все услуги (цены, описания) |
| `texts.ru.ts` | Меню, шапка, подвал (русский) |

**Страницы (вёрстка)** остаются в `src/routes/` — их обычно не трогают, только если нужен новый блок.

**Язык кода:** TypeScript + React (файлы `.tsx`).
