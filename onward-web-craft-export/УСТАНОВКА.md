# Установка понятной структуры в onward-web-craft

Скопируйте файлы в ваш проект **onward-web-craft** (папка с `package.json`).

## 1. Новая папка с текстами

Скопируйте папку **`content/`** → **`src/content/`** в проекте onward-web-craft.

## 2. Файлы в корень проекта

- `README.ru.md`
- `КАРТА_САЙТА.md`
- `docs/vscode-settings.example.json` → в `docs/`

## 3. Заменить файлы маршрутов

Из папки **`routes-patch/`** скопируйте в проект:

| Откуда | Куда |
|--------|------|
| `routes-patch/index.tsx` | `src/routes/index.tsx` |
| `routes-patch/collections.tsx` | `src/routes/collections.tsx` |
| `routes-patch/contact.tsx` | `src/routes/contact.tsx` |
| `routes-patch/i18n.tsx` | `src/lib/i18n.tsx` |
| `routes-patch/services-data.ts` | `src/lib/services-data.ts` |

## 4. Проверка

```bash
npm install
npm run dev
```

Сайт выглядит **так же**, тексты правятся в **`src/content/`**.
